# 📱 Aurora Custom App Template

תבנית לפיתוח אפליקציות Android עצמאיות המיועדות לשילוב ישיר ואוטומטי ב-**Aurora Store Fork**.

---

## 🚀 איך משתמשים בתבנית זו?

1. לחץ על הכפתור הירוק **Use this template** למעלה וצור ריפו חדש תחת החשבון שלך.
2. ערוך את קובץ המניפסט **`aurora-app.json`** בשורש הריפו והגדר את שם האפליקציה, מזהה החבילה והתיאור.
3. שים את אייקון האפליקציה בקובץ **`icon.png`** בשורש הריפו (רזולוציה מומלצת: 512x512).
4. פתח את האפליקציה שלך כרגיל בתיקיית `app/`.

---

## 📦 שחרור גרסאות ופרסום לחנות

בכל פעם שתרצה לשחרר גרסה חדשה שתגיע אוטומטית לחנות:

* צור תגית גרסה ב-Git ודחף אותה:
  `git tag v1.0.0`  
  `git push origin v1.0.0`

ה-GitHub Action ירוץ באופן אוטומטי:
* יקמפל את ה-APK.
* ייצר GitHub Release להורדה.
* ישלח הודעה לדשבורד של Aurora Store.

האפליקציה תופיע אוטומטית בחנות של המשתמשים ותתעדכן שקט דרך Shizuku / Root!
